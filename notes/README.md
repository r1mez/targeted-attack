## 论文笔记

每篇一文件，命名为 `<年份>_<第一作者>_<短标题>.md`，与论文原文名称对应。可按以下结构撰写：

```markdown
# 论文原题

## 来源与引用
- 作者、年份、出处、论文链接、本地原文链接、版本与获取日期
- 作者代码仓库及许可；无法确认的信息标注待核验

### BibTeX
（填入经来源核验的 BibTeX）

## 对目标类别生成的帮助
（首先说明目标类别如何参与生成、优化或搜索，以及直接或间接的用途）

## 任务与访问设置
（图级/节点级、多分类/二分类、定向/非定向、白盒/黑盒、编辑和预算）

## 核心方法
（目标函数、算法流程、约束与最小扰动处理）

## 与本项目的关系
（直接可用/需改造/仅作参考，改造路径及局限）

## 可复用组件
（模块、依赖、许可与移植代价；未找到则说明）

## 实验与证据
（数据、指标、结论，关联论文的章节、表格或图）

## 推断、疑问与待确认决策
（与论文已验证结论明确区分；列出选项和影响）
```

笔记完成后更新 [papers/survey.md](../papers/survey.md)。

## 实验方案

方案命名为 `experiment-<实验标识>-plan.md`，初始状态必须写“待确认”。包含假设、数据集与模型、目标与约束、方法与对照、指标定义、预期结论、smoke test、正式规模、资源及输出路径；确认后记录批准范围与日期。

用户确认前不得运行任何实验，包括 smoke test。仅当批准范围已经覆盖正式实验时，smoke test 通过后才可按方案继续。
